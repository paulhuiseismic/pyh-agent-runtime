# Quickstart: plugin tool 插件机制 + sandbox 验证指南

**目标**: 15 分钟内本地跑通全部验证，全程无需网络、无需真实模型密钥、
无需第三方插件生态。

## 前置条件

沿用 001-004 的虚拟环境，无新增依赖。

## 1. 单元测试（验证 SC-001 / SC-002 / SC-003）

```bash
pytest tests/unit/tool -v
```

**预期**: 全部通过（Windows 上 CPU/内存资源超限相关测试会显示为
`SKIPPED`，并注明"仅 POSIX 硬性生效"，这是预期行为而非失败）。

## 2. stub 演示脚本（验证 US1/US2/US3）

运行示例脚本（实现阶段交付于 `examples/demo_tool_sandbox.py`）：

```bash
python examples/demo_tool_sandbox.py
```

**预期输出依次包含**:

1. 注册两个工具（一个进程内可信实现、一个沙箱插件），列出全部已注册工具；
2. 重复注册同名工具被拒绝；
3. 调用沙箱工具正常执行，返回目标脚本的输出（含参数正确传递的证明）；
4. 调用一个"故意超时"的沙箱工具，在配置的超时时间内被强制终止；
5. 调用一个"以非零退出码退出"的沙箱工具，识别为工具业务失败；
6. 每次调用的 console span 输出，含 `tenant_id`/`tool_name`/`result_type`。
